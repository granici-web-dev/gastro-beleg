## 2. Игроки подробно

### DATEV — два разных продукта, которые постоянно путают

> **Правка после I1 (разговор со Steuerberater, 11.08.2026):** «DATEV пользуются только те, у кого
> большая канцелярия, маленьким заведениям подписка слишком дорога». → **Портал для клиента**
> в нашем сегменте почти не распространён; а вот **софт для канцелярий** — практически везде
> (80–90 % доля рынка среди канцелярий **[F]**).

| | Софт DATEV для канцелярий | DATEV Unternehmen online / Belege online |
|---|---|---|
| Кто платит | канцелярия | клиент (3,75 €/мес.) **[F]** |
| Распространённость | 80–90 % канцелярий **[F]** | в маленьких гастро-заведениях почти нет **[I1, n=1]** |
| Значение для нас | определяет наш **формат экспорта** (EXTF) | **не** наш главный противник |

**Наш реальный противник в сегменте S1 — не DATEV, а обувная коробка**, то есть «не делать ничего».
Победить это проще, чем подписку за 3,75 €, но труднее *назначить срок*: у бездействия нет ни даты
окончания договора, ни триггера.

### DATEV подробно (потому что «достаточно хорошо» и почти бесплатно там, где им пользуются)
- **DATEV Belege online: 3,75 € нетто/мес. на клиента**, включая ревизионно-защищённое хранение. **[F]**
- **DATEV Upload mobil: бесплатное приложение**, сфотографировал документ → он в облаке DATEV. **[F]**
- Upload Mail: пересылка счетов по e-mail, разовая бесплатная активация. **[F]**
- **Чего оно НЕ делает:** нет данных по позициям для ресторатора, нет истории цен, нет сверки
  Lieferschein↔Rechnung, нет логики Pfand, нет аналитики для кухни. **[F]**
- **Вывод для нас:** «мы оцифруем ваши документы» — **не** аргумент для продажи.
  Ресторатор сегодня получает это за 3,75 € через своего Steuerberater.

### Candis — от 50 €/мес. **[F]**
ИИ-workflow для документов, согласования, предварительное разнесение по счетам, SEPA-XML, архив GoBD,
нативный интерфейс к DATEV. Целевая аудитория — **офис** среднего бизнеса с иерархией согласований.
Для гастро на одной точке без бухгалтерии workflow согласований — лишний балласт. Гастро-логики нет.

### lexoffice / Lexware Office, sevDesk — ~10–30 €/мес.
Захват документов через OCR + полная бухгалтерия для малого бизнеса; Lexware прямо продвигает страницу
для гастрономии. Сильная сторона: частично заменяют Steuerberater. Слабая: взгляд **бухгалтерский**
(счёт, USt), а не **закупочный** (артикул, кг, цена за единицу, Pfand).

### FoodNotify — Starter **174,90 €/мес. за одну точку** **[F]** · Apicbase, Heptic — по запросу **[F]**
Полная Warenwirtschaft: рецептуры, остатки, снабжение, мультиплощадка. Именно это наш питч называет
«платформой от 175 €» — **цифра подтверждена**. Для 1–3 точек слишком дорого и слишком тяжело
(ведение рецептур = работа на полную ставку). Они выигрывают у сетей примерно от 5 точек.

### METRO / DISH — стратегическая угроза
Цифровые счета входят в бесплатное приложение METRO; DISH строит гастро-экосистему
(касса, платежи, сайт). **[F]** Сегодня только для закупок в METRO — то есть силос. **[A]** Если METRO
расширит это на сторонних поставщиков, мы потеряем часть клина. Противоядие: взгляд на всех
поставщиков сразу + связка со Steuerberater стратегически неинтересны METRO (они продают товар,
а не бухгалтерию).

### Choco / Kollex — комплементарны, но держать под наблюдением
Платформы заказа, для рестораторов бесплатны, монетизируются через поставщиков. Им принадлежит момент
**заказа**; нам — момент **документа**. Платформа заказа могла бы добавить сверку счетов, но пока не
делает этого, потому что её клиент — поставщик. **[A]**

### restdata.app — наш референс, но не образец для Германии **[R]**
- Тарифы: Starter 23 €/70 документов · Pro 55 €/180 · Scale 95 €/340, пакеты-дополнения не сгорают,
  14 дней / 30 документов бесплатно. **[F]**
- Интеграции: Syrve Cloud, iiko Server, автозабор из METRO, e-Factura (SFS Молдова). **[F]**
- Трекшн по сайту: **8 заведений**, 856 документов, 98 % распознавания, 30 мин → 1,5 мин. **[F]**
- **Переносимость:** их якорь — товароучётная система при POS (Syrve/iiko в СНГ — стандарт).
  В Германии у нашей целевой аудитории Warenwirtschaft **нет** — якорь здесь **DATEV + Steuerberater**.
  Именно поэтому продукт должен выглядеть иначе, хотя ядро (фото → позиции → маппинг → экспорт)
  идентично.

## 3. Что из этого следует для позиционирования

| Неверное позиционирование | Почему проваливается | Верное позиционирование |
|---|---|---|
| «оцифруем документы» | DATEV: 3,75 € + бесплатное приложение | «увидеть, во что закупка обходится на самом деле» |
| «автоматизируем бухгалтерию» | lexoffice/sevDesk дешевле, StB и так это делает | «Steuerberater получает всё чистым *попутно*» |
| «Warenwirtschaft лайт» | будит ожидание остатков и рецептур, которых мы не даём | «никакой Warenwirtschaft. Только правда о ценах» |
| «точность ИИ/OCR» | не проверяемо, 98 % заявляют все | «сигнал при повышении цены» (результат вместо технологии) |
