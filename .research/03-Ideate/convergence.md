# Конвергенция — от 52 идей к 3 концепциям

Критерии в таком порядке:
1. **Работает ли она на первичный POV?** (сделать потерю видимой — [[pov-problem-canvas]])
2. **Нарушает ли она принцип дизайна?** (→ [[design-principles]], критерий на вылет)
3. **Impact** = насколько сильно меняет поведение ресторатора · **Effort** = трудозатраты до первого эффекта

## Impact / Effort

### Quick Wins — высокий эффект, малые трудозатраты
| Идея | Почему |
|---|---|
| **№2/№7 ретро-анализ старых документов** | решает HMW-6 напрямую: доказательство возникает из материала, который уже существует. Не требует новой техники — только извлечения, которое мы и так строим. |
| **№15 Lieferschein ↔ Rechnung** | единственная находка, видимая **сразу** в евро (истории цен нужны недели). |
| **№24 почтовый ящик** | фиксация без участия пользователя. Уже есть в спецификации, трудозатраты низкие. |
| **№36 радар цен (еженедельно)** | повторяющийся контакт = retention, пять строк вместо дашборда (принцип 2 + идея 51). |
| **№22 шаблон рекламации** | превращает находку в возвращённые деньги — доказательство становится выплатой. |

### Отклонено — с обоснованием
| Идея | Причина |
|---|---|
| №34 сканировать бумагу, присланную почтой | нарушает принцип 1 (результат приходит неделями позже), превращает нас в сервисную контору вместо продукта |
| №33 планшет-киоск | железо в заведении = установка, обслуживание, отговорка |
| №47 данные закупок как подтверждение кредитоспособности | чужая бизнес-модель, уводит от POV |
| **продажа обезличенных данных поставщикам** | **конфликт интересов.** Мы представляем ресторатора против поставщика — эта модель уничтожила бы доверие, которое и есть наше единственное преимущество |
| №39 «что если» для цен в меню | граничит с калькуляцией/Warenwirtschaft → Non-Goal (CLAUDE.md) |
| №20 считать по фото паллеты | технически дорого, польза неочевидна, принцип 1 под угрозой |
| №14 пари на недопоставку (выплата 50 €) | продажный трюк с неясной экономикой; №4 (гарантия находки) добивается того же дешевле |

## Выбор

Три концепции, которые вместе обслуживают ровно тот порядок, что задан в [[hmw]]:

| # | Концепция | Обслуживает | Роль |
|---|---|---|---|
| **K1** | **Belegdiagnose** — доказательство из старых документов | HMW-6 | открывает продажу |
| **K2** | **Сторож недопоставок** — Lieferschein ↔ Rechnung + рекламация | HMW-2 | приносит первый евро |
| **K3** | **Тихий сторож** — фиксация без усилий + недельный радар | HMW-4/5/1 | удерживает ценность живой |

K1 без K2 нечего показать. K2 без K3 через четыре недели умирает от нехватки данных.
K3 без K1 никогда не купят. **Эти три — цепь, а не варианты.**
