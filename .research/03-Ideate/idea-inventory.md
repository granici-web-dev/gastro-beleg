## A · HMW-6 — доказать на первой неделе, что в бумагах лежат деньги (ПРИОРИТЕТ)

1. **Диагностика документов на месте** — продавец при первой встрече фотографирует 20 документов из ящика и через 10 минут показывает первый скачок цены.
2. **Ретро-анализ** — ресторатор отдаёт три месяца бумаги, мы разбираем бесплатно и выдаём «вы переплатили X €».
3. **Витрина без регистрации** — загрузить документ на сайте, сразу увидеть разбор по позициям, без аккаунта.
4. **Гарантия находки** — если за первый месяц найдём меньше 39 €, месяц бесплатный.
5. **Региональный тизер** — «сливки 30 % в вашем регионе стоят в среднем 8,40 €, вы платите 9,20 €».
6. **Логин METRO** — подключить историю закупок, тренд цен без единого фото.
7. **E-mail задним числом** — переслать старые PDF-счета из почты, разбор за пять минут.
8. **Задел через канцелярию** — канцелярия (с согласия) отдаёт документы за прошлый год, анализ готов до первого разговора.
9. **Проверка цен как отдельный бесплатный продукт** — пять документов в месяц бесплатно, без подписки.
10. **Демо на чужих данных** — анонимизированный пример сопоставимого заведения.
11. **Бумажный чек-лист** — продавец заполняет «список потерь» вручную вместе с ресторатором, без софта.
12. **WhatsApp-бот** — отправил фото, получил разбор. Ноль установки.
13. **Возврат через семь дней** — продавец приходит через неделю с распечатанным отчётом.
14. **Пари на недопоставку** — не найдём ошибку, платим 50 €.

## B · HMW-2 — сделать недопоставки видимыми, чтобы никто не пересчитывал

15. **Автоматическая сверка Lieferschein ↔ Rechnung** (ядро механики).
16. **Правдоподобие по строке** — количество × цена ≠ сумма строки → флаг.
17. **Отклонение от типичного паттерна заказов** этого поставщика.
18. **Брутто-вес** в Lieferschein против заказа.
19. **Кнопка «чего-то не хватает»** — кухня сообщает без деталей, система ищет остальное.
20. **Фото паллеты/стеллажа** рядом с документом, ящики пересчитываются.
21. **Просьба пересчитать только тогда**, когда этот поставщик статистически подозрителен.
22. **Шаблон рекламации** — в один клик: письмо поставщику + отслеживание Gutschrift.
23. **Замкнуть круг Gutschrift** — «возвращено: X €» как видимый счётчик.

## C · HMW-4/5 — фиксация без внимания

24. **Собственный почтовый ящик** на каждое заведение, поставщики шлют прямо туда.
25. **Приём через WhatsApp** — фото в чат = зафиксированный документ.
26. **Лоток с QR** — вечером одно фото стопки, автоматическое разделение.
27. **Голосовая заметка** — «Metro приезжал, три ящика молока» — сопоставится позже.
28. **Автозабор** из порталов поставщиков (METRO, Transgourmet).
29. **E-Rechnung автоматически** — ноль усилий, растёт вместе с законом.
30. **Напоминание по ритму** — «по вторникам приезжает Molkerei Süd — документ на месте?»
31. **Серия для кухни** — экран на кухне показывает «12 дней полностью».
32. **Поставщик передаёт данные вместе с товаром** (партнёрство, EDI/DESADV).
33. **Режим киоска** — старый планшет у двери приёмки.
34. **Бумажный конверт** — документы раз в месяц почтой, мы сканируем.

## D · HMW-1/3 — от цифры к решению

35. **Пуш при превышении порога** (например, +5 %).
36. **Радар цен по воскресеньям** — пять строк, что изменилось за неделю.
37. **Светофор прямо в списке документов**, а не в отчёте.
38. **Переговорное письмо в одно нажатие** — с историей цены во вложении.
39. **«Что если»** — цена в меню +0,50 € → эффект за месяц.
40. **Сравнение поставщиков на уровне артикула** — у кого тот же артикул дешевле.
41. **Симуляция перехода** — «купили бы в июне у B: сэкономили 180 €».
42. **Дайджест сигналов через WhatsApp** владельцу.

## E · SCAMPER по ядру «сфотографировать документ»

43. **Substitute** — заменить фото на e-mail, забор из портала, E-Rechnung.
44. **Combine** — соединить с кассой: Wareneinsatz против оборота = food-cost **без рецептур**.
45. **Adapt** — модель «выписка по счёту»: список изменений вместо отчёта.
46. **Magnify** — все заведения региона вместе → индекс цен.
47. **Put to other use** — данные закупок как подтверждение кредитоспособности или для получения субсидии.
48. **Eliminate** — убрать приложение целиком: только почтовый ящик + еженедельное письмо (Zero-UI).
49. **Reverse** — загружает не ресторатор, а отправляет поставщик; либо фиксирует канцелярия.

## F · Worst Possible Idea → инверсия

50. Худшая идея: *кухня вбивает все позиции в Excel* → **инверсия:** ноль ввода, только подтверждение сомнительного.
51. Худшая идея: *дашборд с 20 диаграммами* → **инверсия:** одно число, одно действие, больше ничего.
52. Худшая идея: *вести каталог до запуска* → **инверсия:** каталог возникает сам из первых документов.
